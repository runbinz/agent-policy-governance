# apl-telemetry

Call `Metrics::new(configured_scrape_token)?` and apply `metrics.instrument(router)` after composing routes. The token is mandatory, at least 32 visible ASCII characters; no defaults exist. Do not install this middleware when telemetry is disabled. `/metrics` accepts exactly one `Authorization: Bearer TOKEN` header and is excluded from observations. The in-memory registry resets on restart and exposes no host/process/environment secrets.

HTTP request counters and duration histograms use only Axum matched route templates, ten fixed method labels, and five status classes. Unmatched requests share one label. At most 128 distinct trusted templates are admitted; additional templates share the fallback. Histograms have cumulative 1ms–30s buckets plus infinity. This bounds the registry to 129 × 10 × 5 series. Labels never read the raw URI, query, request headers, body, or identity.

Every response receives a fresh UUIDv4 `X-Request-ID`, ignoring incoming request IDs. The downstream handler future is instrumented with that trace ID. Completion events contain only route template, bounded method, status, duration, and generated trace ID. Handler logging must independently obey redaction rules. Router templates are trusted static configuration and must not embed sensitive identifiers. Metrics and logs exclude scrape requests.

Worker ticks and provider calls use typed fixed enums and cumulative counters/duration histograms. `record_internal_dispatch` measures internal work only; callers exclude provider network and human waiting. Unknown and timeout provider outcomes represent indeterminate results; confirmed failure requires verified business failure. Context verification uses `ProviderOperation::Context`; verified unsupported charges use `Ineligible`, while verification ambiguity uses `Unknown`. Provider labels remain bounded to three operations and six outcomes. Counters and histograms reset on process restart.

`set_business(BusinessSnapshot)` replaces global database gauges. The collector starts down, becomes up after a successful snapshot, and `business_failed()` marks it down while retaining all last values and the sample timestamp. Unknown ages (`None`) are omitted, never reported as zero. Negative values clamp to zero; duplicate decision labels aggregate with saturating counts. Only four outcomes and fourteen contract reasons survive canonicalization (at most 56 series), regardless of input size. Untrusted strings and allocations are discarded. Durations use `Duration` and accumulated sums remain finite.

API and worker replicas expose duplicate global snapshots: aggregate business gauges with `max`, never `sum`. Decision counts describe retained rows and may decrease after retention; they are gauges. Protected HTTP scraping remains mandatory for every listener. Compiler checks do not establish execution safety.
